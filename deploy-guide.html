☁️ 云卷云苏 · 部署教程

从小白到上线，跟着做就行，每一步都有说明

1注册 GitHub 账号

GitHub 是一个代码托管平台，我们把代码放上去，Railway 才能自动拉取部署。

  1. 电脑浏览器打开 github.com
  2. 右上角点 Sign up（注册）
  3. 填邮箱、密码、用户名，完成注册
  4. 去邮箱点验证链接，激活账号
已经有账号？ 直接跳到下一步
2在 GitHub 上创建仓库
  1. 登录 GitHub 后，右上角点 + → New repository
  2. Repository name 填：yun-juan-yun-su
  3. 选 Public（公开，Railway 免费版需要公开仓库）
  4. 其他都不用动，拉到底点 Create repository
3下载安装 Git

Git 是把本地代码推到 GitHub 的工具。

  1. 打开 git-scm.com/downloads
  2. 下载 Windows 版，双击安装，一路点 Next，全部默认
  3. 安装完，在桌面空白处右键，应该能看到 "Open Git Bash here"
Mac 用户 Mac 自带 Git，打开"终端"app 就能用。
4解压项目代码到电脑
  1. 把下载的压缩包解压，得到一个文件夹 yun-juan-yun-su
  2. 文件夹结构应该是：
    yun-juan-yun-su/ ├── server.js ├── package.json ├── Dockerfile ├── .dockerignore ├── .gitignore └── public/ └── index.html
注意 Windows 可能自动给 .dockerignore 和 Dockerfile 加上 .txt 后缀，需要去掉。在文件夹里点"查看"→勾选"文件扩展名"就能看到。
5把代码推到 GitHub
  1. 进入 yun-juan-yun-su 文件夹
  2. 在文件夹空白处右键 → 点 "Open Git Bash here"
  3. 依次粘贴执行以下命令（每行回车一次）：
git init git add -A git commit -m "云卷云苏上线" git branch -M main git remote add origin https://github.com/你的用户名/yun-juan-yun-su.git git push -u origin main
⚠️ 第5步 把 你的用户名 换成你 GitHub 的实际用户名！
网络报错？ 国内推送 GitHub 需要代理。开启代理软件的全局模式，或执行：
git config --global http.proxy http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890
要求输入密码？ 需要用 GitHub Personal Access Token（不是账号密码）。去 GitHub → Settings → Developer settings → Personal access tokens → Generate new token，勾选 repo 权限，生成的 token 当密码用。
6用 Railway 部署
  1. 打开 railway.app，点 Login，选 GitHub 登录
  2. 点 New Project → Deploy from GitHub repo
  3. 找到 yun-juan-yun-su 仓库，点选它
  4. 选 Deploy now
  5. Railway 会自动识别 Dockerfile，构建并启动，约1-3分钟
7配置环境变量
  1. 在 Railway 项目页面点击你的 Service
  2. 点击 Settings 标签页
  3. 找到 Environment Variables 区域
  4. 添加以下三个变量：
AI_API_KEY = 你的 DeepSeek API Key AI_BASE_URL = https://api.deepseek.com AI_MODEL = deepseek-v4-pro
获取 API Key 去 platform.deepseek.com 注册，在 API Keys 页面创建，复制 sk-xxx 开头的 Key。
8生成公网地址
  1. 在 Railway 的 Settings 标签页
  2. 找到 Networking / Domains 区域
  3. 点 Generate Domain
  4. 得到一个地址，类似：https://yun-juan-yun-su-xxx.up.railway.app
  5. 手机浏览器打开这个地址就能用了！
✅ 部署成功 打开地址看到"云卷云苏"的进入页面就成功了。
9开始使用
  1. 打开公网地址，输入4位房间号，选男生/女生，点"进入房间"
  2. 发起方：选一个场景，写下想说的事，点"提交倾诉"
  3. 提交后出现邀请横幅，点 🔗 复制链接发给对方
  4. 被邀请方：打开链接，看到引导语，选一个状态（文字可选），点"提交"
  5. 任一方点"请导师回应"
  6. 导师给出 共同解读（双方都看到）+ 给你的话（仅自己看到）

🎉 就这样！
